# App icon

Wordless voice-note mark using the app's coral, cream, and ink palette.

- `app-icon.svg`: opaque 1024 × 1024 vector master for conversion to mobile icon assets.
- `app-icon-foreground.svg`: transparent foreground for an Android adaptive icon; use a solid `#F05B3D` background layer.

The artwork contains only vector paths and shapes, with no fonts, linked images, or embedded bitmaps. The square background intentionally has no rounded corners; apply the platform mask during conversion. These are source artwork files, not installed launcher assets.
